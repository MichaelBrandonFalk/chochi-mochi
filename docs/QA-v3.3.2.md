# Grammar, continuity, and game flow

## Changes

Chapter goodbye pages now retain the same seven page links, read-aloud control, and Back action as the rest of the chapter. The final step is called Say goodbye because gifts already enter the basket when made. Removed repeated project-success text at chapter endings and repeated result text in the finale.

Placing a card keeps keyboard focus on an available card. Final-scene transitions use the normal page renderer to restore main focus, scroll to the start, and apply reading/access controls. Finale replay wording refers to the story notes instead of a newly earned gift.

Garden headings and flower-button labels now use the current gift name, matching the picture and saved creative choice. The final gathering’s basket count shows earned gifts, independently of how many review ideas have been shared. Unchosen companions remain undecided in the home garden plans.

Clarified the mirror-reply project, the mouse inside Olive’s storybook, the painted-pebble ending, the first project’s bench, a quoted sentence, and the recap’s gift name. Updated the play guide to reflect automatic gifts, current replay controls, twelve music tracks, and desktop save files. Teaching principles were unchanged.
